# Arretado — Cozinha Nordestina

Página de restaurante feita no projeto **Restaurant Page** do The Odin Project.

🔗 **Site no ar:** https://jonatasbx.github.io/restaurant-page/

## O que o projeto pratica
- Módulos JavaScript (`import` / `export`)
- Montagem da página pelo DOM com `createElement`
- Troca de abas sem recarregar a página
- Webpack (servidor de desenvolvimento, CSS e imagens)
- Publicação com gh-pages

## Como rodar
npm install
npm run dev

Abra http://localhost:8080
